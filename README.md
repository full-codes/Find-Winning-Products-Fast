# Find-Winning-Products-Fast
Find Winning Products Fast — a local dashboard that scrapes Etsy, AliExpress &amp; Amazon and ranks products with a Winning Score (0–100) built from popularity, rating, price zone &amp; revenue. Web UI with filters, charts, CSV export, demo mode and 30-min cache. Portable Python — no installation, run run.bat. Created by Full Codes (github.com/full-codes).
